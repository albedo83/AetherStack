# Security policy

AetherStack parses files that may be malformed or untrusted. Reports involving
unbounded allocation, integer overflow, denial of service, memory safety, or
path traversal should not initially be filed as public issues.

Please use GitHub's private security advisory workflow for the repository. Include
the affected revision, a minimal reproducer when safe to share, the expected
impact, and any known mitigation. Do not include private astronomical datasets
or identifying FITS metadata.

The project is pre-release. Only the latest revision of the default branch is
currently eligible for security fixes.
